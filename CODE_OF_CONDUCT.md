# Code de conduite

Savio est un projet éducatif. On y vient pour apprendre et aider les autres à apprendre ; chacun doit pouvoir participer sans crainte.

## Ce que nous attendons

- Respect envers chaque personne, quels que soient son niveau, son origine, sa langue, sa religion ou ses convictions, son genre, son âge ou son handicap.
- Critiquer les idées et le code, jamais les personnes.
- Patience avec les débutants : toute question est légitime.
- Sur les sujets religieux, historiques ou politiques : rester factuel, citer ses sources, accepter que des positions différentes coexistent.

## Ce qui n’est pas accepté

- Insultes, harcèlement, menaces, moqueries.
- Propos discriminatoires ou dénigrant une croyance ou un groupe.
- Publication d’informations privées sur quelqu’un sans son accord.
- Prosélytisme ou polémique hors du cadre éducatif d’une discussion.

## Signalement

Écris aux mainteneurs via l’adresse indiquée dans `SECURITY.md` (objet : « Code de conduite »). Les signalements sont traités avec discrétion. Les mainteneurs peuvent retirer des contributions et exclure temporairement ou définitivement les personnes qui ne respectent pas ce code.
